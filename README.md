# 🎓 TuitionHub — Landing Page

Landing page for **TuitionHub**, a Flutter-based Tuition Teacher Management App.
Built with a dark, glowing-glass design and a polyglot browser engine.

## ✨ Highlights

- **3D Hero** — interactive Three.js phone mockup (mouse-reactive), orbit rings, particles
- **Polyglot Engine** — live **Python** (Pyodide), **WebAssembly** (hand-written WAT) & **Lua** (Fengari) running in the browser
- **App Showcase** — pure-CSS phone mockups of the Flutter dashboard
- **Features / How it Works / Download** sections with AOS scroll animations
- Fully responsive (mobile · tablet · desktop)

## 📲 Download

The APK ships with this repo: [`appapk/app-release.apk`](appapk/app-release.apk)
The site's Download buttons serve it as `TuitionHub-v1.0.0.apk` (v1.0.0, 56 MB, Android 6.0+).

## 🚀 Run locally

```bash
# any static server from this folder, e.g.
npx serve .
# or: python -m http.server 8080
```

Then open http://localhost:3000 (or your chosen port).

## 🛠 Tech

HTML5 · Tailwind CSS (CDN) · Vanilla JS · Three.js · AOS · Pyodide (Python) · WebAssembly · Fengari (Lua)
