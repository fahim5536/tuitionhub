## ✨ What is this?

The official landing page for **TuitionHub** — a Flutter app that helps tuition teachers
register, sync data directly to the cloud, and manage students, attendance & payments.

This is **not** an ordinary landing page. It's a polyglot playground:

- 🖱️ **Interactive 3D hero** — a floating phone mockup built with Three.js that rotates as you move your mouse, orbited by rings, particles & wireframe geometry
- 🐍 **Real Python in the browser** — the income calculator runs CPython via Pyodide (watch the `PYTHON ● LIVE` badge)
- ⚙️ **A 98-byte WebAssembly module** — hand-written WAT (xorshift32) forges Sync-IDs
- 🌙 **Lua 5.4 via Fengari** — the codename oracle writes straight into the DOM

## 🚀 Run locally

```bash
git clone https://github.com/fahim5536/tuitionhub.git
cd tuitionhub

# any static server works — this is a zero-build, single-file site
npx serve .
# or: python -m http.server 8080
```
